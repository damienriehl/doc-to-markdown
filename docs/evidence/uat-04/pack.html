EP-D2M-UAT04-011

Export → import round-trip is byte-identical (after data-loss fix)

Pass

Round-trip verified by byte-compare: re-exporting the imported copy produced sources/* and outputs/* byte-identical to the original export (all 5 payload files), and project.json content-equal ignoring volatile id/name/timestamps/blobIds.

DATA-LOSS BUG FOUND & FIXED: importProject reused the chapter blobIds embedded in project.json. The IndexedDB files store is keyed by blobId, so importing a project whose blobIds already existed overwrote (re-parented) the existing blob records, silently deleting the original project's source files. Confirmed live: both the original and first import ended with 0 stored blobs. Fix: importProject now regenerates a fresh blobId + chapter id per chapter on import. Regression test added (exportImport Test 11); full suite 120/120 green; post-fix live re-run shows all projects retaining their own source blobs.

ALL sources+outputs byte-identical: True
